# UI Debug

Contains developer-facing runtime debug overlays.

## Spell Debug Overlay

Useful information includes:

- Equipped spell.
- Cast state.
- Cooldown.
- Resource cost.
- Current target.
- Aim origin.
- Aim direction.
- Server cast ID.
- Last hit actor.
- Last rejection reason.
- Network role.

## Dungeon Debug Overlay

Useful information includes:

- Seed.
- Generator version.
- Room count.
- Critical path.
- Room IDs.
- Room types.
- Encounter budgets.
- Validation status.
- Retry index.

## Rule

Debug UI should expose existing gameplay state.

It must not become part of authoritative gameplay execution.
